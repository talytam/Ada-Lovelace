## Sobre o projeto

A página apresenta uma breve biografia de **Ada Lovelace**, passando por diferentes momentos de sua vida e destacando sua contribuição para a história da computação.

O projeto foi criado como exercício prático de fundamentos de desenvolvimento Web.

## Funcionalidades

- navegação interna entre as seções da biografia;
- conteúdo sobre infância, juventude e vida adulta de Ada Lovelace;
- links para conhecer outras mulheres da história da tecnologia;
- formulário demonstrativo com validação de nome e e-mail;
- layout responsivo para diferentes tamanhos de tela.

## Tecnologias

## Como executar

Não é necessário instalar dependências.

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` em um navegador.
